### Digital Design

#### [Basic Logic Gates](https://github.com/abhichandra586/01-basic-logic-gates)
All seven fundamental gates (AND, OR, NOT, NAND, NOR, XOR, XNOR) implemented in Verilog, each with a dedicated testbench and GTKWave waveform verification against complete truth tables.

![Verilog](https://img.shields.io/badge/Verilog-1f6feb?style=flat-square)
![Icarus Verilog](https://img.shields.io/badge/Icarus%20Verilog-2ea44f?style=flat-square)
![GTKWave](https://img.shields.io/badge/GTKWave-3fb950?style=flat-square)

#### [Combinational Circuits](https://github.com/abhichandra586/02-combinational-circuits)
17 circuits from half-adder to a full 16-bit ALU, including a 16-bit ripple carry adder, adder-subtractor, magnitude comparator and priority encoders. Three key modules are synthesised with Yosys and verified through gate-level simulation.

![Verilog](https://img.shields.io/badge/Verilog-1f6feb?style=flat-square)
![Yosys](https://img.shields.io/badge/Yosys-d29922?style=flat-square)
![GTKWave](https://img.shields.io/badge/GTKWave-3fb950?style=flat-square)
![Graphviz](https://img.shields.io/badge/Graphviz-555?style=flat-square)

#### [Sequential Circuits](https://github.com/abhichandra586/03-sequential-circuits)
D, T, JK and SR flip-flops, 4-bit and 16-bit registers, up, up-down, BCD and Gray code counters, all four shift register modes (SISO, SIPO, PISO, PIPO), and a 256x16 synchronous SRAM.

![Verilog](https://img.shields.io/badge/Verilog-1f6feb?style=flat-square)
![Icarus Verilog](https://img.shields.io/badge/Icarus%20Verilog-2ea44f?style=flat-square)
![GTKWave](https://img.shields.io/badge/GTKWave-3fb950?style=flat-square)

#### [Finite State Machines](https://github.com/abhichandra586/04-finite-state-machines)
Moore and Mealy FSMs, traffic light controller, 1011 sequence detector, UART transmitter and receiver, SPI master and debounce circuit, all with simulation-verified waveforms.

![Verilog](https://img.shields.io/badge/Verilog-1f6feb?style=flat-square)

### Tooling and Automation

#### [Verilog EDA Automation](https://github.com/abhichandra586/verilog-eda-automation)
A Python command-line framework for RTL regression testing. It compiles Verilog with iverilog, runs simulations, parses PASS/FAIL results, and generates an HTML dashboard and JSON report. It supports watch mode, tag-based test filtering, Vivado synthesis report parsing and CI/CD integration. Built with collaborator Sujeet Kona.
